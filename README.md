# Color Palette Studio 🎨

A comprehensive web application for color consultants to manage personalized color palettes for their clients, complete with shopping suggestions and boutique recommendations.

## ✨ Features

### For Stylists/Consultants:
- **16 Standard Color Palettes**: Pre-designed professional color schemes
- **Client Management**: Add, edit, and organize client information
- **Palette Customization**: Modify any of the 16 standard palettes for individual clients
- **Admin Dashboard**: Comprehensive view of all clients and their assigned palettes
- **Database Storage**: All client data is saved and persists between sessions

### For Clients:
- **Secure Access Portal**: Clients log in with email and access code
- **Personalized Color Palette**: View their custom color scheme with hex codes
- **Shopping Suggestions**: Curated recommendations for clothing and accessories
- **Boutique Links**: Direct links to recommended online stores
- **Mobile-Friendly**: Responsive design works on all devices

## 🚀 Getting Started

### For Stylists:

1. **Access Admin Dashboard**: Click "Stylist Dashboard" from the home page
2. **View Standard Palettes**: Browse all 16 available color schemes
3. **Add New Client**: 
   - Click "Add New Client"
   - Enter client name and email
   - Select a base palette
   - Optionally customize colors
   - Client receives an access code automatically
4. **Manage Clients**: Edit or delete existing clients as needed

### For Clients:

1. **Get Access**: Your stylist will provide your email and access code
2. **Login**: Use "Client Access" from the home page
3. **View Palette**: See your personalized color scheme with names and hex codes
4. **Shopping**: Browse curated suggestions and visit recommended boutiques

## 💾 Data Storage

- All data is stored locally in your browser using localStorage
- Client information and custom palettes persist between sessions
- No external database required - works completely offline
- Data includes: client profiles, palette assignments, custom colors, and access codes

## 🎯 How to Use

### Setting Up Your First Client:

1. Go to "Stylist Dashboard"
2. Click "Add Demo Data" to see example clients (optional)
3. Click "Add New Client"
4. Fill in client information
5. Choose a base palette (e.g., "Spring Bloom")
6. Customize colors if needed
7. Save the client

### Client Experience:

1. Share the client's email and access code with them
2. Client visits the website
3. Client clicks "Client Access"
4. Client enters their email and access code
5. Client sees their personalized palette and shopping suggestions

## 🎨 Customization Options

### For Each Client You Can:
- Assign any of the 16 standard palettes
- Modify individual colors within the palette
- Change palette assignment at any time

### Color Customization:
- Click on any color in the customization section

## 🆘 Support & Troubleshooting

### Common Issues:

**Client can't log in:**
- Verify email and access code are correct
- Check that client status is "Active"
- Ensure client exists in the system

**Colors not saving:**
- Make sure to click "Save" or "Update" after making changes
- Check browser localStorage permissions

**Responsive issues:**
- Try refreshing the page
- Clear browser cache if needed
